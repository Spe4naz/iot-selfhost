# OTA firmware

Положите сюда .bin-файлы прошивок. URL раздачи: `https://ВАШ_ДОМЕН/fw/<имя файла>`.

Имя файла должно совпадать со значением `OTA_FIRMWARE` в конфиге прошивки
(например `firmware_esp32_v1.2.0.bin`). Версия прошивки должна быть не ниже
текущей на устройстве, иначе устройство откатит обновление.

В приложении укажите OTA URL: `https://ВАШ_ДОМЕН/fw`.

Каталог монтируется в nginx (`site/fw` → `/usr/share/nginx/html/fw`).
